# roadmap

This branch holds **planning documents only** for the next versions of `sdd-cli`. It has no
code and is never merged into `main`.

- Start at [docs/roadmap/README.md](docs/roadmap/README.md) (in Portuguese).
- The code and the latest release are on [`main`](https://github.com/MarioHBS/Protocolo-SDD).
- When a planned version is opened, its stage is copied to `docs/release/PLAN.md` on that
  version's branch. See `docs/branching.md` on `main`.
