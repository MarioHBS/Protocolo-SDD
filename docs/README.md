The full usage manual ships with the tool: run `sdd manual`
(source: [`src/sdd_cli/content/USAGE.md`](../src/sdd_cli/content/USAGE.md)).

On a version branch there is also a `release/` folder with that version's plan, checklist and
notes; on `main` it holds the latest version's. Versions published before this model was
adopted have no `release/` folder.
